Privacy Policy — BBQOne

Last updated: May 2026

BBQOne is a Chrome extension for personal notes, bookmark backups, and a simple calendar. The extension runs in the extension popup — it does not inject scripts into web pages you visit. This policy explains what data is collected and how it is used.

Local-First Architecture

By default, BBQOne stores your data locally in your browser using chrome.storage.local (and, for sign-in session tokens, chrome.storage.session). We do NOT collect, transmit, or store your content on remote servers unless you explicitly sign in for cloud sync.

This local data may include:

  • Notes, note bodies, and folders
  • Bookmark backup snapshots and related settings
  • Calendar events
  • Extension preferences (e.g. theme, UI language, font size)

What We Do NOT Track

  • Your IP address
  • Your browser fingerprint
  • Your browsing history
  • Your location
  • Personal identity (name, address, phone number)
  • Payment or financial information
  • Any analytics or telemetry

Optional Cloud Sync

If you choose to sign in (e.g. Sign In from the dashboard), BBQOne can sync your data to your configured Supabase project. After signing in:

  • Your data is stored under your account, protected by Row Level Security (RLS) — only your authenticated user can access your own rows.
  • Notes inside Secure Folders are encrypted client-side (AES-GCM) before being sent to the server.
  • You can sign out at any time. The extension continues to work in local mode.

Authentication Credentials

When you opt to sign in, BBQOne uses Supabase Auth for authentication. Your email and password are used only for sign-in. Passwords are not stored in plaintext in the extension — Supabase handles password hashing and security.

No In-Page Translation or Dictionary

BBQOne does not translate text on websites, does not read page content for translation, and does not call third-party translation or dictionary APIs. For translation, use your browser or another tool you trust.

How Data Is Used

Your data is used exclusively to provide the core features of BBQOne. It is never sold, shared, or transferred to any third party for advertising, analytics, or any other purpose.

Data Storage & Security

Local mode (default): Application data is stored in chrome.storage.local, protected by Chrome's extension sandbox. Other extensions and ordinary websites cannot access this storage.

Cloud mode (opt-in): Data is stored in the Supabase backend configured for this build. Transmission uses HTTPS (TLS). Database access is gated by Row Level Security — your auth.uid() must match row ownership.

Your Rights

You can at any time:

  • Delete or edit items through the extension UI
  • Export bookmark backups as HTML from the Bookmarks tab (file saved on your device)
  • Sign out from cloud sync
  • Uninstall the extension to remove local extension data from this browser profile
  • Delete or export your cloud data using your Supabase project / account tools

Third-Party Services

For this version of BBQOne, network access in normal use is limited to:

  • Supabase (*.supabase.co) — Authentication and optional data sync. Used only when you sign in.
  • Google Fonts (fonts.googleapis.com / fonts.gstatic.com) — Loading UI fonts for extension pages. Google's terms and privacy policy apply to those requests.

The extension does not load remote scripts from other domains into web pages; it does not include content scripts on arbitrary sites.

Children's Privacy

BBQOne is not directed at children under 13. We do not knowingly collect personal information from children. If you believe a child has provided us with personal information, please contact us so we can take appropriate action.

Changes to This Policy

We may update this privacy policy from time to time. The "Last updated" date at the top will reflect the latest revision. Continued use of BBQOne after changes constitutes acceptance.
