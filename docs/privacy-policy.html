Privacy Policy — BBQOne

Last updated: May 2026

BBQOne is a Chrome extension for personal note-taking, bookmark management, and dictionary lookup. This policy explains what data is collected and how it is used.

Local-First Architecture

By default, BBQOne stores all your data locally in your browser using chrome.storage.local. We do NOT collect, transmit, or store any of your data on remote servers unless you explicitly sign in.

This includes:

  • Notes and folders
  • Bookmark backups
  • Dictionary entries (saved translations)
  • Translation settings

What We Do NOT Track

  • Your IP address
  • Your browser fingerprint
  • Your browsing history
  • Your location
  • Personal identity (name, address, phone number)
  • Payment or financial information
  • Any analytics or telemetry

Optional Cloud Sync

If you choose to sign in via Settings → Sign In, BBQOne will sync your local data to your private Supabase account. After signing in:

  • Your data is stored in your personal Supabase project, protected by Row Level Security (RLS) — only you can access your own data.
  • Notes inside Secure Folders are encrypted client-side (AES-GCM) before being sent to the server.
  • You can sign out at any time. Future operations resume in local mode.
  • You can also export your local data as JSON before deciding to sync, via Settings → Export Local Data.

Authentication Credentials

When you opt to sign in, BBQOne uses Supabase Auth for authentication. We collect your email and password solely for sign-in purposes. Passwords are never stored in plaintext — Supabase handles password hashing and security.

Translation Service Disclosure

When you use the translation feature, BBQOne uses two providers:

  1. Chrome Built-in Translator API (primary, local). Translation is performed entirely on your device. No data leaves your browser.
  2. MyMemory Translation API (fallback for higher quality). When the Chrome built-in translator is unavailable or returns insufficient results, BBQOne sends the selected text via HTTPS to MyMemory for translation. We do NOT send any personal information, user IDs, IP tracking codes, or browsing context — only the text you selected. MyMemory's privacy policy applies to their service: https://mymemory.translated.net/doc/privacy.php

You can disable MyMemory in Settings → Translation Quality to use only the Chrome built-in translator (100% local, no network required).

English Dictionary Enrichment

For English words, BBQOne fetches phonetic transcription, part-of-speech, and synonyms from Free Dictionary API (dictionaryapi.dev) via HTTPS. Only the English word itself is sent — no user data.

How Data Is Used

Your data is used exclusively to provide the core features of BBQOne. It is never sold, shared, or transferred to any third party for advertising, analytics, or any other purpose.

Data Storage & Security

Local mode (default): Data is stored in chrome.storage.local, protected by Chrome's extension sandbox. Other extensions or websites cannot access this data.

Cloud mode (opt-in): Data is stored in your personal Supabase project. All transmission uses HTTPS (TLS 1.2+). Database access is gated by Row Level Security policies — your authenticated user_id must match the row's user_id to read or write.

Your Rights

You can at any time:

  • Export your local data as JSON (Settings → Export Local Data)
  • Delete individual entries via the extension UI
  • Sign out from cloud sync (Settings → Sign Out)
  • Uninstall the extension to remove all local data
  • Delete your cloud data via Supabase account management

Third-Party Services

BBQOne connects to the following third-party services:

  • Supabase (supabase.co) — Authentication and optional data sync. Activated only when you sign in.
  • MyMemory Translation API (mymemory.translated.net) — Translation. Activated when MyMemory is enabled in settings (default ON).
  • Free Dictionary API (api.dictionaryapi.dev) — English word enrichment. Activated when you save an English word.

Children's Privacy

BBQOne is not directed at children under 13. We do not knowingly collect personal information from children. If you believe a child has provided us with personal information, please contact us so we can take appropriate action.

Changes to This Policy

We may update this privacy policy from time to time. The "Last updated" date at the top will reflect the latest revision. Continued use of BBQOne after changes constitutes acceptance.
