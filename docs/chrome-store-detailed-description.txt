Local-first notes, bookmarks, and calendar. Optional cloud sync and Google Calendar link. Private and offline-capable.

BBQOne is a privacy-minded productivity extension with local-first defaults. Capture notes, back up bookmarks, and plan your day with a built-in calendar — all from one clean, compact dashboard.

Works offline. No account needed. Sign in only if you want cloud sync.

═══════════════════════════════════════════════════
KEY FEATURES
═══════════════════════════════════════════════════

NOTES
Rich text editing with code syntax highlighting, folders, and full-text search. Rename, move, or delete from each row's menu. Optional passphrase-protected secure folders (client-side AES-GCM encryption).

BOOKMARKS
Snapshot, browse, search, and restore your Chrome bookmark tree. Export as HTML. Backups sync to your account when you sign in.

CALENDAR
Month view with up to 3 events per day. Repeat events weekly, monthly, or yearly. Search across all events. Today and tomorrow at a glance in the header. Mark an event done with one click, and tick off overdue items one by one.

GOOGLE CALENDAR LINK (OPTIONAL)
Signed in? Create a private, one-way link in Settings › Google Calendar and add it in Google Calendar ("From URL"). Your BBQOne events then appear in Google Calendar. Google decides when to refresh the link — usually within several hours. Turn the link off or replace it at any time.

CLOUD SYNC (OPTIONAL)
Sign in with email and password to sync notes, bookmark backups, and events across devices. Changes made offline sync automatically when you're back online. Each account's data is isolated by server-side Row Level Security.

DESIGN
Clean layout with a compact side rail for Calendar, Notes, and Bookmarks. Light and dark themes. English and Vietnamese interface. Undo for deletes.

═══════════════════════════════════════════════════
PRIVACY-FIRST
═══════════════════════════════════════════════════

No account required. No ads, no analytics, no tracking.
No content scripts — BBQOne cannot read or modify the pages you visit.
Without sign-in, your notes, bookmarks, and events stay on your device; the only network request is the Inter font from Google Fonts. After sign-in, BBQOne talks only to its Supabase backend for sign-in and sync.

Encrypted before upload: notes in secure folders. Regular notes, folders, bookmark backups, and calendar events are stored under your account, isolated by Row Level Security.

Google Calendar link: created only if you ask for it. Anyone with the link can read your calendar, so keep it private — you can replace or turn it off in Settings.
