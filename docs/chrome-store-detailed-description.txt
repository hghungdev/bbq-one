Local-first notes, bookmarks, and calendar. Optional cloud sync. Privacy-respecting, offline-capable.

BBQOne is an all-in-one productivity extension built around privacy and local-first defaults. Capture notes, back up bookmarks, and plan your calendar—from the same compact, retro-inspired dashboard.

Release 1.2.1: Faster popup load (cache-first), offline-friendly edits with auto-sync when online, calendar overdue reminder on sign-in, and UI polish.

Release 1.2.0: Translation and personal dictionary flows have been removed to keep scope smaller and disclosures simpler. The extension does not inject translation UI into web pages. The dashboard still offers UI language (English / Vietnamese) and theme controls. Optional cloud sync via Supabase is unchanged.

═══════════════════════════════════════════════════
PRIVACY-FIRST DESIGN
═══════════════════════════════════════════════════

By default BBQOne keeps notes, bookmarks, and calendar state on your machine unless you explicitly sign in for sync.

No mandatory account. No analytics or ads bundled for "product tracking."
Optional sync: Sign in through Supabase when you want multi-device continuity—HTTPS in transit plus server-side Row Level Security so only your account reaches your rows.

Network use in plain language
Extensions cannot be "offline only" forever if you turn on cloud sync—you choose when:

Supabase (auth + optional data sync) is used only after you sign in
Extension pages may load Google Fonts for typography (see Privacy Policy)

We do not run a behavioral ad network inside BBQOne. We do not need your browsing history as a feature. Read the Privacy Policy below for hosting, accountability, and what Supabase sign-in implies.
