# BBQOne — Chrome Web Store Listing Copy

## Short Description (132 chars max)
Local-first notes, bookmarks, and personal dictionary. Optional cloud sync. Privacy-respecting, offline-capable.

## Detailed Description

BBQOne is an all-in-one productivity extension that respects your privacy.

### What it does

📝 **Notes** — Take notes with rich formatting and organize them in folders.
Code blocks support syntax highlighting for 10+ languages.

🔖 **Bookmarks** — Backup, search, and manage your Chrome bookmarks with
encrypted secure folders for sensitive items.

📚 **Personal Dictionary** — Translate words and phrases on any webpage.
Save translations to build your personal vocabulary database. Supports
9 languages (EN, VI, JA, ZH, FR, DE, ES, KO, TH).

### Local-First Privacy

By default, ALL your data stays on your device. No cloud account required.
No tracking. No analytics. No ads.

When you want multi-device sync, you can opt-in to sign in with Supabase —
your data is encrypted in transit and protected by Row Level Security.

### Translation

- **Primary**: Chrome built-in translator (100% local, offline)
- **Fallback**: MyMemory API for higher quality (can be disabled in
  Settings for strict privacy)
- **Enrichment**: For English words, optional phonetic + synonyms from
  Free Dictionary API

### Why BBQOne?

- ✓ Works offline by default
- ✓ Optional cloud sync (your choice)
- ✓ Open about every external service used (see Privacy Policy)
- ✓ Vintage 1989 retro aesthetic
- ✓ Export your data anytime as JSON

### Permissions Explained

This extension requires several permissions to provide its features:
- Read selected text on webpages (translation)
- Read/write Chrome bookmarks (bookmark feature)
- Inject UI on webpages (translation popup)

We do NOT track your browsing history or collect personal data. Full
permission justification: see "Permissions" section below.
